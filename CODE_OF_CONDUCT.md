# Código de Conduta

Esperamos que todas as pessoas participantes sejam tratadas com respeito e possam colaborar em um ambiente seguro, inclusivo e profissional.

Não são aceitos assédio, discriminação, ameaças, exposição de dados pessoais, publicação de credenciais ou comportamento deliberadamente abusivo.

Relatos podem ser enviados de forma privada ao proprietário do repositório pelo GitHub. O projeto pode remover conteúdo ou participação que viole este código.
